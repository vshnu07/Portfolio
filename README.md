## 🚀 Technologies Used
- **React.js**: For building a dynamic and responsive user interface.
- **Node.js & Express.js**: Powering the backend with scalable and secure APIs.
- **MongoDB**: Efficient data management using advanced aggregation pipelines.
- **Three.js & React Three Fiber**: Integrating immersive 3D elements (where applicable).
- **Tailwind CSS**: For modern, utility-first styling.
- **Framer Motion**: Adding smooth micro-animations for an enhanced UI/UX.

## ✨ Key Features
- **Scalable Architecture**: Built with MVC patterns, JWT-based security, and role-based access control.
- **Modern UI/UX**: Responsive design that looks great on all devices.
- **Dynamic Content**: All project and certification data is easily manageable via a central constants file.
- **Integrated Contact Form**: Seamlessly connect with visitors.
